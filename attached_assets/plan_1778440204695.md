# Arch Linux Graphical Installer — Engineering Master Plan

## Project Objective

Build a bootable Arch Linux installer environment that launches a fullscreen Tauri-based graphical installer inside i3.

The installer must:

* Boot from USB or dedicated partition
* Use a minimal stripped-down Linux runtime
* Automatically launch into i3
* Open the installer application in fullscreen
* Provide a polished Windows 11 OOBE-style guided setup flow
* Use real Linux system data (disks, partitions, hardware)
* Write configuration to `/installer/configs/config.json`
* Execute installation through `/installer/scripts/install.sh`

---

# Core System Architecture

## Layer 1: Boot Environment

Minimal Linux environment containing:

### Required Components

* Linux kernel
* init system
* i3 window manager
* Ghostty terminal
* Tauri runtime dependencies
* cfdisk
* filesystem tools
* mount utilities
* networking tools
* Rust backend support libraries

### Boot Behavior

On successful boot:

1. Initialize runtime environment
2. Execute startup script
3. Launch i3 session
4. Configure workspace layout
5. Launch installer fullscreen

---

Path:

`/installer/scripts/startup.sh`

Responsibilities:

* Initialize environment variables
* Run preflight checks
* Create required directories
* Initialize config state
* Launch i3
* Start installer
* Handle auxiliary processes

### Frontend

### Backend

## Layer 4: Installation Executor

`/installer/scripts/install.sh`

# Install Script Requirements

Path:

`/installer/scripts/install.sh`

## Format Root Partition

Using selected filesystem.

## Format Boot Partition

FAT32

## Set Partition Type

EFI System Partition

## Mount

Root:

`/mnt`

Boot:

`/mnt/boot`

Then continue Arch installation.
